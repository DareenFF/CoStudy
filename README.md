## Overview 
CoStudy is a website that helps students choosing courses based on their interests, college courses and grades.

## Tech stack
1. HTML,CSS and JS for the frontend.
2. ASP.NET CORE for the backend.
3. Python API for the recommendation algorithm

## Main features
1. Portfolio creation
2. Courses page with search
3. Admin panel for data management
4. Sign up / Log in
5. Recommended courses page associated with the created portfolio.
